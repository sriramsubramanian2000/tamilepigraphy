On real undeciphered corpora, this is the genuinely useful layer: sign-frequency distributions, positional statistics, and recurring sequences can suggest formulae, word-boundaries, or structural regularities — long before any sign is "read" in the linguistic sense. Comparative Study

Tamil script across periods
✓ Real: Tamil-Brahmi and Modern Tamil glyphs below are genuine Unicode characters, correctly rendered. Vatteluttu has no reliable Unicode font, so it is shown as a described placeholder rather than an invented glyph.

The broad, cautiously-stated trajectory: Tamil-Brahmi (as attested in cave and pottery inscriptions from roughly the 2nd century BCE, per Iravatham Mahadevan's corpus) gives way over centuries to Vatteluttu ("round script"), and later to the Grantha-influenced square Tamil script that underlies the modern alphabet. The changes are gradual — loop simplification, vowel-marker evolution, retention or loss of Brahmi-derived stroke forms — which is exactly the kind of quantifiable diachronic data a palaeographic model would need. This comparison panel is illustrative; a real study would need many dated exemplars per letter, not one representative glyph.
